# Ecosystem

Packages by the same author that work well with BillGameCore. Each lives in its own repository and
installs by git URL. None of them depends on BillGameCore.

## Editor tools

### BillFav

Favourites for the Project window: pin assets and folders into pages, drag and drop to reorder,
switch pages with the mouse wheel or number keys, and an overlay inside the Project browser.

```text
https://github.com/billtruong003/BillFav.git#v1.0.0
```

[Repository & docs](https://github.com/billtruong003/BillFav)

### BillSceneSwitcher

A scene dropdown on Unity 6.3's main toolbar: searchable list grouped by folder, favourites, recent
scenes, open additively, and **Play from bootstrap** (always enter Play Mode through scene 0, then
return to the scene you were editing). Requires Unity 6000.3+.

```text
https://github.com/billtruong003/BillSceneSwitcher.git#v2.0.0
```

[Repository & docs](https://github.com/billtruong003/BillSceneSwitcher)

## Rendering

### Bill SS Outline

Screen-space outline for URP 17 (Render Graph): depth, normal and colour edges, outline only the
objects on chosen rendering layers, occlusion mask, distance/height fade, and an alpha-mask path that
avoids a second draw for large crowds.

```text
https://github.com/billtruong003/Bill-SSOutline.git#v2.0.0
```

[Repository & docs](https://github.com/billtruong003/Bill-SSOutline)

### Stylized Toon World Kit

31 hand-written HLSL shaders for URP 17: toon lighting, outline, environment (water, grass, trees,
terrain, sky), surfaces (glass, metal, ice, lava, crystal, liquid), VFX and anime NPR. Includes a
Showcase sample.

```text
https://github.com/billtruong003/stylized-toon-world-kit.git?path=/Assets/StylizedToonWorldKit#v0.7.0
```

[Repository & docs](https://github.com/billtruong003/stylized-toon-world-kit)

### Bill VAT

Vertex Animation Textures: bake `SkinnedMeshRenderer` clips into textures and play them on a
`MeshRenderer` with GPU instancing, for hundreds of animated enemies.

```text
https://github.com/billtruong003/BillVAT.git#v1.0.0
```

[Repository & docs](https://github.com/billtruong003/BillVAT)
